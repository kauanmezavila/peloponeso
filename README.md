# Peloponeso

### Uma livraria livre para descobrir, guardar e continuar lendo.

O Peloponeso é uma biblioteca digital feita para deixar os livros mais perto. Explore o acervo, abra uma leitura no navegador e volte depois à página em que parou.

## Leia do seu jeito

- **Explore o acervo:** encontre livros por título, autor ou categoria.
- **Continue de onde parou:** o progresso de leitura fica salvo neste navegador.
- **Monte sua estante:** favorite livros para encontrá-los com facilidade.
- **Compartilhe bibliotecas:** adicione outros catálogos usando uma chave e compartilhe-os com outras pessoas.

O acervo da Peloponeso está disponível em [kauanmezavila/peloponeso-library](https://github.com/kauanmezavila/peloponeso-library). Também é possível adicionar catálogos públicos compatíveis pelo menu **Bibliotecas**.

**Peloponeso — leia no seu tempo. Volte quando quiser.**
